FINITY 2.5

A Chromium/Electron desktop browser with a custom home screen, tabs, Google search/address navigation, saved website shortcuts, shortcut management with individual delete buttons, YouTube Music with toolbar controls, dark and warm light themes, Google sign-in flow, and optional typewriter-style keyboard sounds.

The Gravity game and FINGPT placeholder have been removed in this version. Typewriter sounds can be toggled from the left sidebar below YouTube Music and work in FINITY pages and embedded website tabs. The sound preference is saved on this device.

Windows build: use the included GitHub Actions workflow.
